# TAssist

[![CI Status](https://github.com/AY2627S1-CS2103T-T10-2/tp/workflows/Java%20CI/badge.svg)](https://github.com/AY2627S1-CS2103T-T10-2/tp/actions)

![Ui](images/Ui.png)

**TAssist is a desktop application for tutors managing student information.** While it has a GUI, most of the user interactions happen using a CLI (Command Line Interface).

* If you are interested in using TAssist, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing TAssist, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
